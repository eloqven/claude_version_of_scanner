# Plan: 1s Archive + Fibonacci Matrix V3 Implementation

## Summary

Implement two components on top of existing V2 source-independent candle core:
1. **Part 1**: 1s archive scraper for Binance Spot data
2. **Part 2**: Fib Matrix V3 research script for Fibonacci confluence analysis

## Requirements (U-IDs)

### Part 1: 1s Archive Scraper

| U-ID | Requirement | Priority | Risk |
|------|-------------|----------|------|
| R-001 | Create `scanner_v2/archive.py` with `ArchiveCandleSource` implementing `CandleSource` protocol | Must | P1 |
| R-002 | Implement URL construction for Binance 1s archive ZIP and CHECKSUM files | Must | P1 |
| R-003 | Implement checksum verification (SHA256) for downloaded files | Must | P1 |
