# Solution: YAML Frontmatter for opencode Skills Recognition

## Problem
opencode skills were not being recognized by the CLI. The `/ce-*` commands were unavailable despite creating `SKILL.md` files in `.opencode/skills/`.

## Solution
Added YAML frontmatter (`name`, `description`) at the top of each `SKILL.md` file. opencode requires this frontmatter to parse and register skills. Also configured `skills.paths` in `opencode.jsonc` to point to the skills directory.

## Key Decisions
1. Each skill gets its own subdirectory under `.opencode/skills/`
2. Every `SKILL.md` starts with YAML frontmatter containing `name` and `description`
3. `opencode.jsonc` includes `skills.paths` configuration

## Files Changed
- `.opencode/skills/*/SKILL.md` - Added YAML frontmatter to all 33 skill files
- `opencode.jsonc` - Added `skills.paths` configuration
- `.opencode/skills/index.json` - Created manifest file
- `.opencode/skills/README.md` - Created inventory and migration guide
